# Curated IP as Logo thumbnails

The 16 WebP files in this directory are selected 512 px thumbnails from
[IP as Logo Skill](https://ipaslogo.com/). Their source URLs, original names,
integrity hashes, and intended Phi resource kinds are recorded in `catalog.json`.

The source website describes the collection as free mascot logos and states that
the images are free for commercial use. This notice records that source statement;
retain it and the catalog when redistributing these thumbnails.
