## What's Changed

### In-app update dialog, verified downloads, and direct replacement

- **In-app release notes and download progress**: clicking an update notice in **Messages** or **Settings -> General -> Check for updates** now opens an in-app **Application Update** dialog displaying version details and formatted Markdown release notes instead of jumping to an external browser tab.
- **SHA-256 verified streaming downloads**: downloads platform installers directly inside Phi using system proxy settings, shows live download progress and byte counts, supports cancellation and resume-free local cache reuse, and verifies every downloaded package against the release's `SHA256SUMS.txt` before allowing installation.
- **Platform-aware replacement and relaunch**:
  - **Windows x64 (`.exe`) & Linux (`AppImage`)**: gracefully stops active local workers, replaces the current installation in place, and relaunches Phi automatically.
  - **macOS Apple Silicon (`.dmg`) & Linux (`.deb`)**: opens the SHA-256 verified local installer directly on screen and exits the running older version cleanly so you can finish replacing the app without browser downloads (preserving all data in `~/.phi`).

## 中文摘要

- **应用内更新弹窗与更新日志展示**：点击“消息中心”的新版本提醒或 **设置 -> 通用 -> 检查更新** 后，直接弹出应用内版本更新窗口，展示版本号对比与 Markdown 更新说明，不再直接外跳浏览器。
- **流式下载进度与强制 SHA-256 完整性校验**：复用系统代理在应用内直接下载对应平台安装包，实时展示下载进度条与体积、支持随时取消与已校验缓存复用，并在下载完成及启动安装前双重核验官方 `SHA256SUMS.txt` 哈希值。
- **按平台完成旧版替换升级**：
  - **Windows x64（`.exe`）与 Linux（`AppImage`）**：安全停止本地运行中进程后，自动静默覆盖旧版本并重新启动新版 Phi。
  - **macOS Apple Silicon（`.dmg`）与 Linux（`.deb`）**：直接调起已通过 SHA-256 校验的本地安装程序并退出旧版本，无需打开浏览器手动查找下载文件；升级全程保留 `~/.phi` 数据。
