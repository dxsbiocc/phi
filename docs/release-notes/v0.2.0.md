## What's Changed

### Public beta ecosystem and on-demand capability setup

- **In-chat MCP sign-in and two-stage external skill approvals**: when an agent run or capability install encounters an unauthenticated MCP connector, Phi presents an inline OAuth or API-key authentication card directly inside the conversation instead of sending you to Settings. External `find_skills` (`skills.sh`) queries and GitHub skill installations now require explicit two-stage user confirmation with source and commit SHA security warnings.
- **Expanded Phi Packages catalog alignment**: pinned and validated against the latest [Phi Packages](https://github.com/dxsbiocc/phi-packages) catalog covering **2,207 Nextflow Wrappers** (2,073 modules, 121 subworkflows, and 13 complete pipelines), **24 specialist domain plugins**, **52 research and workflow skills**, and **25 MCP connectors** (including 9 self-hosted biomedical and multi-omics gateways).
- **Fast direct skill and prompt-agent loading**: home-screen preload and direct skill/agent scanning keep startup and catalog switching responsive, with cached catalog refresh indicators across providers, plugins, skills, wrappers, and connectors.

### Managed environments, Windows x64 stability, and WSL2 guidance

- **Leaner `phi-python` and `phi-r` base environments**: moved heavy domain dependencies into isolated plugin environments (`plugin:viz` and domain plugins), added a native `win32-x64` lock for `phi-r`, and pinned OpenBLAS (`nomkl`) on Windows x64 `phi-python` so `scikit-learn` (`llvm-openmp`) never collides with Intel MKL OpenMP in native Jupyter notebooks.
- **Built-in environment diagnostics and guided remediation**: added `env_diagnose`, controlled `env_build` / `env_setup_wsl` tools, and the bundled `environment-setup` core skill so missing Nextflow or WSL2 prerequisites surface clear, actionable setup cards.
- **Unified environment management and non-blocking uninstalls**: Settings -> Environment now inspects installed base, plugin, skill, and MCP private environments with lock integrity checks and package cache trimming, while resource removals execute asynchronously in Background Jobs without blocking the UI.

### Public beta notes

Phi **0.2.0** marks the first public beta release, with installers for **macOS arm64**, **Linux x64** (`.AppImage`, `.deb`), and **Windows x64** (`.exe`).

- macOS builds are ad-hoc signed without Apple Developer ID notarization; allow the app once under **System Settings -> Privacy & Security -> Open Anyway**.
- Windows builds are unsigned, so Windows SmartScreen may prompt on first run. Native Windows Python 3.12 and Jupyter power local chat and Python notebooks; R, Nextflow, and Linux-only bioinformatics packages run via WSL2.
- Updates are manual via **Settings -> General -> Check for updates**. Upgrading preserves all data in `~/.phi`.
