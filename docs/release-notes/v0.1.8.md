## What's Changed

### Scientific planning, context contracts, and provenance

- Structured plans now include an explicit literature-review decision with DOI, PMID, PMCID, and arXiv citation verification, plus competing falsifiable hypotheses with declared statistical replication units.
- Plan steps support closed-list post-step checks (`file_exists`, `non_empty_file`, `json_valid`, `table_schema`) across both local and SSH remote workspaces, cross-checking reported quantitative metrics against workspace QC tables and JSON outputs before marking a step complete.
- Completed wrapper runs and write-mode script tools emit `.phi-context.json` sidecars with real SHA-256 digests and sample/donor provenance. Downstream steps preflight `inputContracts` before launch, detect upstream evidence staleness, and can derive targeted rerun plans without overwriting prior run history.
- Plan runs can compile a provenance-bound report anchoring key metrics, frozen wrapper snapshots, and notebook environment metadata, while flagging post-hoc replans or untested selected hypotheses.

### Wrappers, reproducibility, and managed Notebook kernels

- Local single-wrapper and multi-step composition runs now share the same primary-output completion check and support bounded read-only output content assertions, samplesheet mate/lane validation, and structured QC metric extraction (FastQC, fastp, Salmon, featureCounts, STAR).
- Wrapper runs freeze an immutable manifest snapshot and capture runtime provenance (Nextflow version, container runtime and image digests, host OS/arch) at execution time; reproducibility bundles include a completeness audit and deterministic rerun guide.
- Saved `.ipynb` notebooks record the executed managed `envId` and `lockSha256` digest in metadata, and installed Phi plugins can contribute managed Notebook kernels from their declared environments.

### Chat, session lifecycle, and platform reliability

- Local kernel sessions restore live context-window usage reporting, fold running agent steps and thinking blocks by default with bounded scroll viewports, omit copy actions on intermediate status summaries, and let an empty composer accept a suggested next action with `ArrowRight`.
- Message editing matches composer dimensions, renders edited prompts immediately when sending starts, and inserts queued prompts as follow-ups on active runs.
- Stopping an ordinary session cleans up active commands and retries, startup callbacks cannot reopen windows during shutdown, SSH password bootstrap no longer hangs behind inherited background pipes, concurrent BSD ripgrep activations serialize cleanly, and Windows runtime fetching verifies bundled VC runtime DLL sidecars.

### Internal beta notes

Phi 0.1.8 is an internal beta, not a stable general release. Packages target macOS arm64, Linux x64, and Windows x64; clean-machine desktop acceptance has not been completed for every target.

- macOS builds for this beta are ad-hoc signed, without formal Developer ID notarization. Gatekeeper asks you to allow the app once under **System Settings → Privacy & Security**.
- Windows has no code signing configured, so SmartScreen may warn about the unsigned installer. Windows x64 remains a preview target while native x64 hardware validation continues.
- Updates are manual: install the new build over the old one. Your data stays in `~/.phi`.
