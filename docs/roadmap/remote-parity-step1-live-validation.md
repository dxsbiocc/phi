## 安全规则（沿用 E01 验证记录）

- 只在你**事先建好的随机名子目录**里操作，例如 `phi-live-<随机ID>`；结束后只删这个子目录。
- helper 只会写入 `$HOME/.phi/remote/0.1.0/`（家目录不可写或不可执行时是 `${TMPDIR:-/tmp}/phi-remote-<uid>/0.1.0/`），不碰其他位置。
- 不要在共享集群上点「安装 Nextflow」；不要改服务器的 shell 启动文件；不要在登录节点留常驻进程。
- 记录里**只写版本和结果**，不写用户名、真实主机名、私有绝对路径、密钥、环境变量。主机用「GPU」「HPC」这样的代号。
- 任何一步失败：保留失败步骤和脱敏后的错误，停下来，不要把此前的模拟测试当作通过。
