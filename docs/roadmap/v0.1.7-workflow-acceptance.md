## Product fixes and review

1. `src/kernel/worker/outbound.ts`: child tool approvals now belong to their child
   run, rather than the parent prompt run. Previously a normal parent completion
   silently cancelled a still-active child approval; the UI could subsequently
   record approval although the kernel had already denied execution. A failing
   regression and the unmodified published app reproduced this problem. Parent
   approvals still cancel normally. Tests cover actual child cancellation with
   and without a live parent, late replies, and protocol-level session isolation.
   Reusing parsed string fields removes repeated branching without changing
   validation semantics.
2. `src/main/agent/notebook/analysis-jupyter-sessions.ts`: local project and
   Notebook paths are canonicalized before computing the relative Jupyter path.
   `/tmp` versus `/private/tmp` aliases previously produced an outside-root path
   and HTTP 500 before cell execution. Independent review caught a potential SSH
   regression in the initial fix; SSH now uses POSIX lexical paths exclusively,
   without reading the desktop filesystem. Local-link and SSH regressions pass.

Regression files: `tests/kernel-worker-outbound-run-binding.test.ts`,
`tests/child-approval-abort-integration.test.ts`,
`tests/kernel-interaction-core.test.ts`, and
`tests/analysis-jupyter-sessions.test.ts`.

Split-or-keep judgment: the existing Notebook session registry is 830 lines.
