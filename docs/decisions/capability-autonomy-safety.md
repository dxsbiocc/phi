# 能力自主扩展与安全管控

日期：2026-10-17
更新：2026-10-18（评审修订，见文末）

设计：[能力自主扩展与安全管控设计](../design/capability-autonomy-safety.md)

- 本设计**不进入内部测试版**。现有 `capability_search` / `capability_install` / `find_skills`、每次智能体安装需审批及 [package 合约](../contracts/package.md)保持当前行为；未来自动安装官方能力须先升级合约与实现。
- 产品目标是补齐能力后继续原任务，以任务完成、必要打断、失败恢复和结果可追溯性验收。安装量和创建量不作为核心成功指标。
- 不设置“标准 / 扩展 / 自由创建”三级能力模式。普通会话只使用官方路径；项目会话可检索第三方能力并在任务结束后产生学习草稿。
- reviewed 官方能力（签名有效、人工审查、可复现构建、固定内容 hash）可以搜索、按需自动安装和使用；首次安装展示结果而不要求安装审批。官方身份限于内置或由 Phi 信任的密钥验证签名的内容；当前未签名的官网内容仍属于 `imported`，按第三方处理；只有签名而未审查的官方内容仍需一次确认。安装不授权数据外发、删除或费用操作。
- 第三方先检索元数据，再暂存内容进行不执行代码的静态检查。用户查看确切来源、内容、用途和权限后一次确认安装计划；宿主再安装、受限试运行并在批准项目内启用。同一安装文件可集中管理，另一项目要使用仍须批准启用。计划、内容或权限变化须重新批准。拒绝后不能换工具执行同一操作。
- 自动学习在已完成的项目任务之后检查重复流程，使用仍获准保留的会话执行记录，不以审计日志摘要重建能力，也不启用常驻或定时监控智能体。草稿可自动产生并保存，但不能自行执行、发布或跨项目启用。用户一次批准受限试运行及通过后加入项目；失败保留草稿。缺少预期结果时不得标为已验证或进入自动执行候选。
- 能力按任务适用条件筛选；来源验证、样例验证和本次输出检查分开显示。可选的独立审查模型只能加严，缺席时不显示通过语义审查，也不替代宿主强制检查。
- 文件、网络、进程、资源、凭据、费用和敏感数据范围由宿主强制执行，覆盖 OMP 工具、子智能体与受控扩展。第三方和学习所得代码没有可验证隔离时保持禁用；远程与 HPC 执行端缺少同等约束时不开放。具体数据外发、删除及凭据用途变化按一次边界明确的业务操作授权。
- 每个能力 `type` / `id` 只有一个全局活动版本。升级仍需用户确认，展示受影响项目，已运行任务先完成；后续任务使用新版。结果记录原版本，重新运行时提示版本变化及结果可能不同。旧版及依赖可取得并验证时允许回滚，不承诺始终可回滚或撤销外部影响。Phi 软件与 OMP 的更新分别管理。
- 结果保留实际能力版本、来源、内容 hash、模型和环境等方法记录，历史记录不锁住项目未来运行版本，也不保证新版本产生相同结果。
- 长期审计只记录安装和版本变化、批准与拒绝、启用和安全拦截；普通搜索和工具调用在内部运行日志中的元数据沿用短期保留期，会话时间线仍按会话规则保存。项目关联审计随项目保存并可在删除项目时清除，全局安装记录保留到用户明确清理。对话正文不进入审计；自动学习读取获准保留的项目会话记录而非审计日志。
- 内置高频、需要严格正确性的能力继续由官方维护。自动扩展补充长尾需求；connector、plugin 的自动创建及远程/HPC 能力在必要的执行保障具备后再开放。

## 2026-10-18 评审修订

- 官方自动安装进一步限于 **reviewed 官方集合**：签名有效、人工审查、可复现构建并在目录中固定内容 hash。只有签名而未审查的官方内容仍须一次确认；签名本身不再构成免审批资格。宿主检查吊销清单并拒绝降级，密钥轮换经应用更新分发。
- 运行期与构建期统一由**单一执行经纪人**强制：权限 manifest 编译为文件、网络出口、凭据与资源预算；skill、脚本工具、wrapper、MCP stdio、OMP 扩展、子智能体，以及环境构建、依赖解析和 MCP 下载都经同一路径。没有经纪人时不开放新的免审批执行路径。
- 安装与授权分为 `install` 与 `grant` 两个对象；撤销、过期、重新确认与审计作用于 `grant`。卸载或停用不等于撤回已经发生的数据外发、费用或不可逆删除。
- 学习草稿由已完成任务的执行记录确定性生成，模型只负责命名、描述与归类；草稿保留会话/项目血缘，来源删除或策略收紧时失效。“已验证”要求可重复的期望结果，环境或依赖变化后降级为未验证。
- 项目默认固定在批准 `grant` 时的能力版本，全局活动版本只作为新项目和新任务的默认值；升级需项目内确认，或至少在下个任务开始前提示。在此之前不得静默替换。
- 审计由宿主进程写入智能体无法改写的位置，使用只追加分段与哈希链；做不到时只能作为运维证据，不能当作对抗性证据。
- 验收增加反向指标：自动安装能力在后续任务中的复用率，以及安装后被停用、回滚或降级的比例。
- 实施顺序调整为：执行经纪人 → reviewed 官方白名单 → 第三方 → 学习。构建期与运行期同时落地；connector、plugin 的自动创建仍后置。
