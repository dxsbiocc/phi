## RFdiffusion 生成满足约束的蛋白质骨架

**论文：** Watson 等，_De novo design of protein structure and function with RFdiffusion_，Nature（2023）；DOI：[10.1038/s41586-023-06415-8](https://doi.org/10.1038/s41586-023-06415-8)。

**论文事实：** 方法通过结构去噪生成骨架，可接受结合靶标、功能基序或对称性条件。作者对设计的组装体、金属结合蛋白和结合蛋白进行了实验表征；结合蛋白研究使用 BLI 测量，部分设计用冷冻电镜核验结构。成功案例支持这些受测任务，不等于任意靶点均可成功，也不等于催化位点支架已获得催化活性。[原文正文与图 6](https://pmc.ncbi.nlm.nih.gov/articles/PMC10468394/)

**仓库事实：** 无条件生成需要长度与采样设置；条件生成还需输入 PDB、链及残基映射，按任务提供基序、界面热点或对称性。输出包括骨架 PDB、含配置与残基映射的 `.trb`、轨迹。生成区以甘氨酸表示，仍需序列设计。必须核对 checkpoint 与条件兼容性；partial diffusion 要求指定长度与输入一致；裁剪靶标可能暴露人为疏水面。当前仓库配置不能直接当作 2023 年论文设置。[官方 README](https://github.com/RosettaCommons/RFdiffusion)

## ProteinMPNN 为给定骨架设计序列

**论文：** Dauparas 等，_Robust deep learning–based protein sequence design using ProteinMPNN_，Science（2022）；DOI：[10.1126/science.add2187](https://doi.org/10.1126/science.add2187)。

**论文事实：** 方法按骨架环境生成氨基酸序列，支持跨位置、跨链的序列耦合。研究对单体、组装体和结合蛋白进行了表达、结构及功能验证，并用 X 射线晶体学、冷冻电镜等核验部分设计。原文强调，天然序列恢复只是计算基准；实际折叠和功能仍需实验。保护功能所需残基是重设计的重要前提。[原文正文与图 3、4](https://pmc.ncbi.nlm.nih.gov/articles/PMC9997061/)

**仓库事实：** 输入为 PDB 或解析后的骨架，配合设计链、固定位置、耦合位置及采样配置；输出为序列及模型评分，可保存逐位概率。完整骨架模型与仅 Cα 模型需匹配输入。评分是序列条件概率的统计量，不能解释为亲和力或活性。[官方 README](https://github.com/dauparas/ProteinMPNN)

## 拟议智能体规则

以下均为待基准验证的工程建议：

1. **需要新骨架时先路由 RFdiffusion，已有骨架时路由 ProteinMPNN。** 若链标识、残基映射或必要坐标缺失，停止依赖该输入的生成，返回具体缺项；不猜测关键残基。
2. **基序或热点属于硬约束时，生成后重新检查其保留与可接近性。** 若不满足项目预先定义的几何条件，淘汰并记录原因；在预算内调整兼容配置，耗尽预算即停止。
3. **序列设计后再做结构复核与多样性筛选。** 若固定功能残基被改变则拒收；若结构一致性不足或候选持续重复，返回诊断。即使计算通过，也只标为“待实验”，不宣称结合或催化成功。

建议每次运行记录：论文 DOI 与对应段落、工具 Git commit、模型权重名称及校验值、完整配置、随机种子、输入文件哈希、链和残基映射、父候选编号、输出文件引用、评分定义、淘汰原因及计算预算。实验结果另行关联，保留阴性结果。
