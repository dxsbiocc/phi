# Phi 论文大纲：跨步骤科学上下文验证

2026-11-18 · 写作底稿。依据[发表计划](publication-strategy-2026-11-17.md)和[开发任务与实验验收](../roadmap/publication-development-tasks.md)。下文是拟报告的研究问题、方法和证据位置；机制、实验及结果按实际进展填入。临床或生物学课题尚未选定。

## 工作题目和主线

**Phi: context-aware execution and verification of scientific workflows**

在智能体组装的科学分析中，一步运行成功、产物格式正确，下一步仍可能拿错样本、参考版本或数据类型。本文拟检验：**在模型、工具和资源相同的条件下，让每一步核对上游产物的科学上下文，能否减少无效结果被报为成功？这种检查会给有效任务带来多少误阻断、人工求助和计算代价？**

这里的上下文指样本与供体身份、物种和参考版本、矩阵单位及变换状态等可追溯信息。论文需要分开回答三件事：产物能否被下游正确使用、最终产物是否符合独立评分标准、真实生物学结论是否有独立数据支持。前一个结论不能替后一个结论作证。

按 [Nature Methods Article 指南](https://www.nature.com/nmeth/content)组织：无引文摘要不超过 150 词，常规正文预算 3,000 词，最多 6 项主图表；本文暂排五张主图。英文正文预算可先分为引言约 450 词、Results 约 1,950 词、Discussion 约 600 词，Online Methods 另计。标题与投稿定位等结果确定后再定。

## Abstract

可先保留以下英文开头，使用研究目的表述：

> An analysis can run without errors even when its inputs no longer match the original study design. We ask whether checking sample identity, reference versions and data transformations at workflow step boundaries improves the reliability of agent-directed analyses. Phi is designed to record these properties alongside artifacts and check whether they meet the requirements of each downstream step.

实验结束后补两句：第一句交代同模型主对照、有效任务的独立科学评分，以及跨步骤故障上的效果和区间；第二句限定证据覆盖的数据与流程，保留重要代价或失败。摘要不填预实验计划数量当正式样本数，也不以单个应用案例推断普适性。

## Introduction（正文不设标题）

1. **用一个分析决定交代后果。** 以差异表达为例：两张矩阵可以有相同的基因行和样本列，却分别存放原始计数和变换后的值。如果下游方法要求原始计数，接收了错误矩阵就偏离了预设分析。这个示例先解释为何文件格式和进程状态不足以判定科学有效性，具体系统表现留到图 1 和图 3。
2. **界定已有工作解决了什么。** [Nextflow](https://www.nature.com/articles/nbt.3820)提供可移植的计算工作流，[Paper2Agent](https://www.nature.com/articles/s41586-026-11044-y)展示了研究代码的工具化、测试和环境配置，[CellVoyager](https://www.nature.com/articles/s41592-026-03029-6)展示了智能体分析在组学研究中的用途。这些工作构成执行、验证和探索的基础。将问题落到步骤交接：单个工具已通过验证时，在动态组装的流程中显式核对每次产物交接，是否仍有可测量的增益？不根据文献描述直接断言竞品缺少某机制。
3. **提出方法及可证伪预期。** 将样本、参考和数据语义记录在产物上，下游声明所需条件。兼容时继续；明确不兼容时停止该步骤并指出冲突；证据不足时请求补充。执行成功后还要核对指定输出。当上游证据变化时，重新检查受影响的下游。预期该机制能减少其覆盖范围内的错误，同时可能增加正常任务的等待或求助。
4. **交代论文如何检验。** 先用 RNA-seq 展示可执行机制；再用有效任务、故障对和严格消融区分收益与代价；最后用一个真实组学问题和独立环境重跑界定研究用途。正式稿在这一段末尾填入实际贡献及限制。

## Results

以下英文小标题采用中性表述，可作为稿件工作标题。每节按“问题 → 对照或验证 → 定量结果 → 解释边界”写作。结果段中的数字、判断和图注均以可追溯记录为准。

### 1. Scientific context at workflow step boundaries

**首段**定义产物具备哪些可核对属性，区分执行观测、来源声明和未知信息。**次段**沿一条从 FASTQ 到定量、差异表达和通路分析的链路，说明何时检查输入、何时判定输出有效，以及改变上游产物后如何重新判断下游能否运行。说明受控计划和工具边界的覆盖范围；自由编写的任意代码不自动受这些规则约束。

**Fig. 1｜方法与真实运行轨迹（E2、E3）。** a，以上游定量和下游差异分析为例画出产物与约束；b，展示一次经独立评分的实际运行及其关键输出；c，展示一对只改变一项上下文的正常/异常输入，标出检查位置、判定和后续行为。示意部分明确标记；单次轨迹用于解释机制，跨任务结果见图 3。

### 2. Scientific accuracy and cost on valid tasks

**首段**说明任务与专家参考怎样确定，用独立产物评分衡量有效输入上的科学表现。**次段**在相同模型、工具和预算下比较完整 Phi 与仅移除跨步骤检查的版本；通用智能体比较用于衡量整体系统差异。公开系统只在共同支持的子集比较，单列资源或模型差异。**末段**同时报告科学评分、完成率、费用与人工干预；按预先划定的第二模型和保留任务检查结果是否保持，不能推广到未运行的模态或流程。

**Fig. 2｜正常任务表现及代价（E1、E3、E6、E7）。** a，任务组成和对照覆盖；b，逐任务配对科学评分及汇总效应区间；c，第二模型与保留任务的效应；d，模型费用、执行时间与人工干预。R19 的 36 次运行仅校准链路、方差和预算，正式比较须另按冻结协议执行。

### 3. Detection and propagation of cross-step errors

**首段**在匹配的正常/异常任务和自然失败上，比较完整系统与严格消融。消融仅关闭跨步骤科学阻断，保持模型、工具、上下文可见性及基础产物验收一致。**次段**并列报告错误成功报告、故障检出、正常误阻断、未知和后继误启动；错误成功报告同时给出以宣称成功次数为分母的比例及其分子分母，并展示所有试验的最终去向。**末段**用同一规则的固定专家流程区分普通质量检查和动态流程中的收益，展示至少一个规则不能识别或误判的情形。

**Fig. 3｜机制收益及失效边界（E2、E6）。** a，各组按故障类型的结果分布；b，匹配正常输入的误阻断与求助；c，自然失败与失效传播的代表性事件链；d，固定流程和保留组合中相同检查的表现。若改进来自普遍拒绝执行，必须与图 2 的正常任务表现一起解释。

### 4. Biological application and external validation

**首段**先提出一个领域科学问题，例如某细胞程序与某种治疗反应是否相关；待确定具体研究对象及数据后替换示例。**次段**写发现队列如何提出候选、哪些分析选择由人确认、何时冻结候选和方法，以及哪一个流程衔接会实质影响分析。**末段**以供体为适当统计单位，在独立队列报告关联效应、区间、混杂控制和敏感性结果，并解释不一致或阴性结果。若无独立队列，只能写成已完成的应用示范或技术验证，不保留该节英文标题的验证主张。

**Fig. 4｜生物学问题与外部证据（E4）。** a，发现/验证队列和冻结节点；b，发现队列的主要对比；c，独立队列及敏感性分析的效应与区间。若仅观察到关联，报告关联强度和适用人群，不写成因果机制。疾病/条件、数据编号、分组、主要对比和反证标准先进入课题卡。

### 5. Independent replay and recovery from execution interruptions

**首段**用一个固定分析案例，检验第二环境是否仅凭复现包和声明的公共资源重跑，说明实际追加的人工步骤及差异。按产物分别核对字节一致、预设容差内数值等价，以及科学解释是否一致。**次段**另报真实 SSH/Slurm 作业中断后的恢复、重复调度、错误启动和人工接管，区分接口恢复与科学产物通过。两类实验各有分母，单一恢复案例不能替代独立重跑。

**Fig. 5｜独立复现与研究负担（E5、E7）。** a，复现包到第二环境的证据链；b，逐产物重跑差异；c，实际故障下的恢复结局和重复计算；d，人工介入时间及其原因。调度日志和环境差异明细放扩展数据。

## Discussion

写成四个连续自然段。第一段直接回答主问题：正常任务得到怎样的结果，核心消融支持多大的机制收益，这两点之间是否有代价。第二段解释与已有工具验证和固定工作流的关系：如果相同的确定性规则已能解释收益，就将贡献限定为规则的表示、接入和应用证据。第三段解释独立案例和复现给研究者带来的实际用途，披露数据准备、规则编写和人工接管。末段讨论元数据本身可能有误、声明外的自由代码无法核对、保留任务覆盖有限、模型版本变化，以及这种检查不能判断任意统计推断或生物学解释。

若只在预设故障上看到收益，保留故障检出结论，弱化真实研究可靠性主张；若正常任务代价较大，报告适用条件及取舍；若独立验证为阴性，保留定义明确的分析和验证结局。发现路线只有在生物学结果可独立成立时再另行组织。
