Phi logo redesign

Six vector directions for a local-first desktop AI workbench. The exploration keeps the soft loop memory of the current icon while making the mark sturdier, more technical, and easier to read at app-icon scale.

Recommended: Orbit

This direction is closest to the existing lowercase-p memory, but it reads more like Phi: a stable vertical spine, an active session loop, and one warm node for background agent activity. It is the safest candidate for replacing the current app icon after review.

Recommended
