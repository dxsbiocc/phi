# Phi Logo Redesign Exploration

This folder contains a non-destructive v2 logo exploration for Phi.

## Direction

Phi is a local desktop AI workbench for project-bound agent sessions, approvals, resources, and recoverable local history. The recommended direction keeps the hand-drawn loop from the current app icon, but makes it more stable and workbench-like:

- rounded phi/orbit silhouette for continuity with the current lowercase `p`
- stronger monoline geometry for small app-icon sizes
- one accent node to imply background sessions and agent activity
- colors from the app theme: navy, teal, turquoise, and orange

## Files

- `phi-logo-v2.svg` is the recommended flexible logo mark.
- `phi-app-icon-v2.svg` is the recommended app icon composition.
- `phi-logo-01-orbit.svg` through `phi-logo-06-flow-ribbon.svg` are six distinct exploration variants.
- `phi-logo-exploration.html` is a local comparison board.

## Notes

The existing app icon files are intentionally untouched. If this direction is approved, replace `resources/icon.png`, `build/icon.png`, and regenerate `build/icon.icns` / `build/icon.ico` from `phi-app-icon-v2.svg`.
