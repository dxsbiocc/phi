# Phi Logo v4: Lowercase φ

This version corrects the previous direction: the mark must be lowercase `φ`, not uppercase `Φ`.

## Correct Shape Grammar

The lowercase mark should read as a compact working symbol with:

- a descending stem that extends below the bowl
- one asymmetric lower loop/bowl
- a slightly hand-shaped trace rather than a centered uppercase ring
- no balanced crossbar, no centered four-way symmetry

## Product Meaning

Instead of diagramming implementation details, v4 focuses on the product promise:

> Phi makes local agent work traceable, bounded, and recoverable.

Symbol mapping:

- the descending stem is continuity across a session
- the loop is the local project workspace
- the lower trace is the run history returning into the workbench
- the small terminal node is the visible point of agent activity
