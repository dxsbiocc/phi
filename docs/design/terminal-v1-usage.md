# 终端 V1 使用说明

## 打开与管理

点击工作区右上角的终端按钮打开面板。首次打开会为当前项目创建一个本地 Shell；点击 `+` 可创建更多终端。

- **收起终端面板**：只隐藏面板，终端、输出和正在运行的程序继续保留。
- **结束终端**：关闭当前终端及其中的进程。
- **结束全部**：关闭当前项目的全部终端，不影响其他项目。

终端按**项目**归属；切换同一项目中的聊天不会更换终端。应用内浏览器不同，它跟随当前聊天切换。

## 键盘与粘贴

- `Ctrl+C`：把中断信号发送给前台程序。
- `Cmd+C`：有选区时复制选中文本；不会代替 `Ctrl+C` 中断程序。
- `Cmd+V`：粘贴。单行按普通终端输入；多行先显示预览，确认“发送到终端”前不会进入 Shell。
- `Cmd+K`：清空当前终端的可见缓冲，不结束 Shell。

## Agent 辅助

“帮我写命令”和“让 Agent 解释”只生成可编辑内容，绝不会自行运行命令。点击“发送到 Terminal N”会把草稿连同回车一起写入终端，即立即提交给 Shell 执行（多行粘贴预览不会追加回车）。命令草稿只能明确发送一次；如果当前行已有输入，必须先确认“我已准备好接收此命令”。

模型只会看到本次请求，以及你主动附加的终端选区；它不会自动读取完整终端、环境变量或聊天历史。

## 支持范围

- 已验证：macOS arm64；终端 Worker 需要系统可用的 Bun。
- 未验证：macOS x64、Linux、Windows、签名/公证安装包。
- 远程项目暂不支持终端；不会回退为本地 Shell。
- 退出 Phi 会清理已登记的终端进程树，但不保证清理用户通过 `nohup`、`disown`、`setsid` 或重归属方式脱离的进程。
