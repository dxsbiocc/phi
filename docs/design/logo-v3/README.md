# Phi Logo v3: Meaning-First Exploration

This pass responds to the critique that the previous icon was visually pleasant but thin on meaning.

## Brand Thesis

Phi is not a generic AI chat app. It is a local desktop workbench for people who run real project-bound agent work. The logo should encode a small system:

- **Local field**: work happens in a bounded local project space, not in an anonymous cloud.
- **Four active lanes**: the beta supports up to four running or approval-blocked sessions globally.
- **Approval threshold**: project work has a visible safety gate before high-risk operations.
- **Recoverable timeline**: sessions and runs are recorded as durable local history.
- **Operator, not mascot**: the mark should feel like a mathematical/operator symbol more than a cute assistant.

## Recommended Direction

`phi-logo-v3.svg` / `phi-app-icon-v3.svg` use the **Phase Gate** direction.

Symbol mapping:

- the outer broken loop is the local project boundary and permission edge
- the vertical spine is the stable Phi session identity
- the lower curved lane is the current run path returning into the session timeline
- the four outer nodes are the beta's four global running/approval-blocked sessions
- the center node is the active selected session
