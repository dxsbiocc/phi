Phi logo v3

A meaning-first redo. Instead of treating Phi as a soft handwritten letter, these marks compress the actual beta system: local project boundary, durable sessions, four concurrent lanes, and visible approval thresholds.

Recommended: Phase Gate

This is no longer just a loop. The broken ring is the local project boundary and approval edge, the vertical line is stable session identity, the lower curved lane is the active run, the four outer nodes encode the beta's four global running/approval-blocked sessions, and the center node is the selected session.
