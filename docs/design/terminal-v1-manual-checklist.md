# 终端 V1 人工检查清单

以下项目需要在 macOS 真机应用中手动验证；自动化测试不能替代这些检查。

T5 记录（2026-10-04，`feat/terminal-v1`）：macOS arm64、Bun 1.3.14、zsh。Codex 的执行环境无法启动 GUI，界面验收由 Claude 在仓库外复制的 unpacked 安装包中完成：隔离的 HOME 与 `--user-data-dir`、最小 PATH、通过 Chrome DevTools 协议驱动并截图。该方式不能代表真实键盘与输入法，因此中文输入法、真实模型草稿、拖动宽度等项仍需人工确认。验收中发现并修复一个缺陷：安装包中 Worker 路径解析返回了 app.asar 内路径（Electron 报告其存在，但 Bun 无法读取），导致终端无法启动；现优先使用 app.asar.unpacked 路径，并有回归测试。

- [x] 打开本地项目，点击右上角“终端”，首次打开只创建一个 Shell。（2026-10-04 安装包实测：普通工作区首次打开只创建一个 Shell；本地项目入口未单独测）
- [x] 连续执行 `cd`、`export PHI_TERMINAL_TEST=1` 和后续命令，确认目录与环境变量在同一终端中保持。（2026-10-04 安装包：`cd /tmp && export FOO=bar` 后 `pwd; echo $FOO` 输出 `/tmp`、`bar`）
- [ ] 验证 Tab 补全、上下方向键历史和常用控制键。
- [ ] 使用中文输入法输入并提交中文，确认组合输入与显示正常。
- [ ] 无选区时按 Ctrl+C，确认前台程序被中断；有选区时按 Cmd+C，确认只复制选中内容。
- [ ] 粘贴单行文本，确认按普通终端方式输入；粘贴多行文本，确认先出现预览，取消不会发送，点击“发送到终端”后才一次发送。
- [ ] 在终端菜单选择“帮我写命令”，生成一个容易辨认但无副作用的命令；确认生成完成时终端没有输入，编辑草稿后点击“发送到 Terminal N”才写入并提交。
- [ ] 生成带必填参数的命令草稿；确认参数未填写时不能发送，填写后命令预览中的占位符被替换，发送成功后不能再次发送同一草稿。
- [ ] 在当前终端行先输入几个字符，再准备发送 Agent 草稿；确认必须勾选“我已准备好接收此命令（当前行已有输入）”后才能发送，且 Phi 没有自动发送 Ctrl+U 或 Ctrl+C。
- [ ] 选中一段终端输出，通过右键或菜单选择“让 Agent 解释”；确认附带内容可编辑、可移除，未主动附带的终端内容不会进入请求，生成解释不会写入 PTY。
- [ ] 生成草稿期间切换到其他终端或工作区再返回；确认迟到结果仍绑定原终端，并且切换过程没有自动发送任何内容。
- [x] 在未配置有效模型时打开 Agent 辅助；确认显示“请先在设置中配置模型”，同时手动终端输入输出仍可用。（2026-10-04 开发构建显示该提示；安装包因 OMP 运行时 Worker 未能启动，60 秒后显示“生成超时”，手动终端不受影响。OMP 打包问题另案处理）
- [ ] 拖动面板宽度并执行 `stty size`，确认行列数更新；连续拖动结束后的最终尺寸也正确。
- [x] 放大终端后确认主内容区隐藏且终端仍为同一进程；还原后确认回到此前面板宽度。（2026-10-04 安装包：放大后输出按宽屏重排，同一 Shell；还原正常）
- [ ] 收起面板时运行持续输出命令，稍后重新打开，确认终端与输出仍在且 Shell 未重新创建。
- [ ] 切换到其他项目或聊天再切回，确认各工作区终端互不混淆，原终端继续运行。
- [ ] 使用菜单结束单个终端和当前工作区全部终端，核对确认文案、数量与退出状态。
- [x] 退出应用后检查没有遗留测试进程，例如运行 `ps -ax | grep -c '[s]leep 300'`；检查前先记录预期基线数量。（2026-10-04 安装包：终端内运行忽略 SIGHUP 的 `sleep 300` 后关闭主窗口，`sleep 300` 与 Worker/Supervisor 全部退出。注：对安装包发 SIGTERM 时，即使未打开终端应用也不退出，属于终端之外的既有问题）

已在安装包中实测、但对应条目还包含未覆盖内容的项：Ctrl+C 中断 `sleep 30`（Cmd+C 复制未测）；多行粘贴先出现预览（行数显示正确），单行粘贴与“发送到终端”在开发构建测过；收起后重新打开输出仍在；新建 Terminal 2 后选择器显示两个终端，各自输出独立。
