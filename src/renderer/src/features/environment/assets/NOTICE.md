# Environment logo sources

These unmodified brand assets are used only to identify the corresponding runtimes in Phi's environment settings.

- `python.svg`: Python Software Foundation logo device, from <https://www.python.org/community/logos/>. Python and the Python logo are trademarks of the Python Software Foundation; Phi is not affiliated with the PSF.
- `r.svg`: R Foundation official vector logo, from <https://www.r-project.org/logo/>. Copyright 2016 The R Foundation, distributed under CC BY-SA 4.0.
- `jupyter.svg`: Project Jupyter official homepage logo, from <https://jupyter.org/assets/homepage/main-logo.svg>. Jupyter and the Jupyter logos are trademarks of LF Charities; Phi is not affiliated with Project Jupyter.
- `nextflow.svg`: Nextflow official Brand Green icon, taken without path changes from the official Seqera brand asset at <https://brand.seqera.io/img/nextflow-logos.svg>.
- `apptainer.svg`: Apptainer official color icon, from <https://github.com/apptainer/apptainer-logos>. Copyright 2022 The Apptainer Container Project, BSD-3-Clause.
